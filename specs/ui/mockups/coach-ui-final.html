First-run setup (setup code) · FirstRun.dc.html

Set up this installation

Nobody has claimed this installation yet. Enter its one-time setup code to create the first administrator.

Where the code comes from
1It is printed by a command run on the machine itself, never shown on this site.
2On a gym base station, whoever installed it has the code. Online, the person who created your installation sends it to you.
3It works once and expires. After that this screen never appears again.

You will be the first administrator. You can add the other coaches afterwards.
